# Hi, I'm Cezary

I build local-first, human-in-the-loop AI products with an emphasis on inspectable decisions, explicit authority boundaries, and evidence-backed iteration.

My current work sits between product design and implementation: Python services, TypeScript interfaces, evaluation harnesses, and the operational details that make agent behavior trustworthy.

## How I Work

- start with a narrow vertical slice and explicit acceptance criteria
- separate model judgment from deterministic authority and safety gates
- keep private data local and make public fixtures unmistakably synthetic
- test the behavior users depend on, not only implementation details
- document decisions, limitations, and what the evidence does not prove
